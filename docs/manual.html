ภาพรวมระบบ

ระบบจัดการข้อมูลพนักงาน (Employee Management System) ใช้งานผ่านเว็บเบราว์เซอร์ ช่วยให้ฝ่าย HR จัดการข้อมูลพนักงาน บันทึกการขาด ลา มาสาย และ OT คำนวณเงินเดือน ส่งคำขอเปลี่ยนตำแหน่งหรือแผนก และดูรายงานสรุป ผู้บริหารอนุมัติคำขอและตรวจสอบรายงาน ส่วนพนักงานดูข้อมูลของตัวเองได้

ผู้ใช้แบ่งเป็น 3 กลุ่ม ได้แก่ ฝ่าย HR, ผู้บริหาร และ พนักงานทั่วไป แต่ละกลุ่มเห็นเมนูไม่เหมือนกัน (ดูหัวข้อ "สิทธิ์การใช้งาน") คู่มือนี้แสดงเฉพาะหัวข้อที่เกี่ยวกับสิทธิ์ของคุณ

การเข้าสู่ระบบและบัญชีผู้ใช้

เข้าสู่ระบบ

  1. เปิดเว็บของระบบในเบราว์เซอร์
  2. กรอกชื่อผู้ใช้ (คืออีเมลของพนักงาน) และรหัสผ่าน
  3. ติ๊ก "จดจำการเข้าสู่ระบบ" ถ้าต้องการให้ยังล็อกอินอยู่หลังปิดเบราว์เซอร์ (ไม่ควรใช้บนเครื่องสาธารณะ)
  4. กด "เข้าสู่ระบบ" ระบบจะพาไปหน้าแรกของสิทธิ์นั้น เซสชันหมดอายุเองใน 8 ชั่วโมง

เปลี่ยนรหัสผ่านด้วยตัวเอง

  1. กดปุ่ม "🔑 เปลี่ยนรหัสผ่าน" ที่แถบด้านบน (ใช้ได้ทุกสิทธิ์)
  2. กรอกรหัสผ่านปัจจุบัน รหัสผ่านใหม่ (อย่างน้อย 8 ตัวอักษร) และยืนยันรหัสผ่านใหม่
  3. กด "บันทึก" เมื่อสำเร็จจะมีข้อความแจ้ง และใช้รหัสใหม่ในการล็อกอินครั้งถัดไป

ข้อควรรู้

  • ใส่รหัสผ่านผิดครบ 5 ครั้ง (ทั้งหน้าล็อกอินและหน้าเปลี่ยนรหัสผ่าน) บัญชีจะถูกล็อก ต้องติดต่อฝ่าย HR หรือผู้ดูแลระบบเพื่อปลดล็อก
  • ลืมรหัสผ่าน ให้ติดต่อฝ่าย HR เพื่อรีเซ็ต
  • กด "ออกจากระบบ" ที่มุมขวาบนทุกครั้งที่ใช้งานเสร็จ

บัญชีตัวอย่างและรหัสผ่านเริ่มต้น (สำหรับ HR)

สิทธิ์ถูกตรวจที่ฝั่งเซิร์ฟเวอร์ด้วย แม้พิมพ์ที่อยู่หน้าอื่นเองก็เข้าถึงข้อมูลที่ไม่มีสิทธิ์ไม่ได้

สีของปุ่มและการแจ้งเตือน

  • ปุ่มน้ำเงินทึบ คือการดำเนินการต่อ เช่น บันทึก เพิ่ม ส่งคำขอ ส่วน ปุ่มขอบน้ำเงิน ใช้กับการดาวน์โหลด อัปโหลด หรือเปลี่ยนรูป
  • ปุ่มเขียว คือยืนยัน/อนุมัติ ปุ่มแดง คือยกเลิก/ลบ/ไม่อนุมัติ
  • ก่อนบันทึกหรือลบข้อมูล ระบบถามยืนยันในกรอบเหลือง ("คุณต้องการ ... ใช่หรือไม่") และเมื่อเสร็จจะมีแถบแจ้งเตือนสีเขียว (สำเร็จ) หรือสีแดง (มีปัญหา) มุมขวาบน
  • กดรูปและชื่อของคุณที่มุมขวาบนเพื่อดูข้อมูลส่วนตัว เปลี่ยนรหัสผ่าน หรือออกจากระบบ

คู่มือสำหรับฝ่าย HR

ข้อมูลพนักงาน

  • ค้นหา พิมพ์รหัส ชื่อ แผนก หรือตำแหน่งในช่องค้นหา (ไม่สนตัวพิมพ์เล็กใหญ่) และกรองเพิ่มด้วยรายการแผนกหรือตำแหน่ง ตารางแสดงหน้าละ 8 คน
  • ดู กดปุ่ม "ดู" เพื่อเปิดโปรไฟล์ของพนักงาน
  • เพิ่มพนักงาน กด "+ เพิ่มพนักงาน" กรอกชื่อ นามสกุล อีเมล (ใช้เป็นชื่อผู้ใช้ ซ้ำกับคนอื่นไม่ได้) วันเริ่มงาน แผนก ตำแหน่ง (รายการตำแหน่งจะกรองตามแผนกที่เลือก) และสิทธิ์ จะกรอกเบอร์โทร ที่อยู่ วันลาคงเหลือ และหัวหน้าด้วยก็ได้ แล้วกดบันทึก ระบบสร้างบัญชีล็อกอินให้อัตโนมัติ
  • แก้ไข แก้ได้ทั้งชื่อ อีเมล เบอร์โทร ที่อยู่ วันลาคงเหลือ และหัวหน้า (เลือกตัวเอง หรือลูกทีมของตัวเองเป็นหัวหน้าไม่ได้) การเปลี่ยนแผนกหรือตำแหน่งต้องทำผ่านเมนู "เปลี่ยนแผนก/ตำแหน่ง/สิทธิ์" (ในกลุ่ม "ข้อมูลแผนกและตำแหน่ง")
  • รูปโปรไฟล์ เปิดโปรไฟล์แล้วกด "เปลี่ยนรูป" เลือกไฟล์รูปภาพ ระบบจะตัดเป็นภาพสี่เหลี่ยมจัตุรัสและย่อขนาดให้อัตโนมัติ

บันทึกขาด ลา มาสาย และ OT

  1. เลือกเมนู "การเข้างาน" (ขาด ลา มาสาย) หรือ "การทำงานล่วงเวลา (OT)"
  2. เลือกพนักงานและวันที่ เมนูขาด ลา มาสายให้เลือกประเภทด้วย ส่วนเมนู OT ให้ใส่จำนวนชั่วโมง (ทีละ 0.5)
  3. กด "บันทึก" แล้วกด "ตกลง" ในหน้าต่างยืนยัน รายการจะแสดงในตารางของวันนั้น และกล่องด้านขวาสรุปจำนวนของวันที่เลือก
  4. ถ้าบันทึกผิด กด "แก้ไข" หรือ "ลบ" ที่ท้ายแถวของรายการนั้นได้

เงินเดือน

  1. เลือกเมนู "เงินเดือน" เลือกเดือนและรอบ (รอบที่ 1 คือวันที่ 1-15 รอบที่ 2 คือวันที่ 16-สิ้นเดือน) แล้วกด "คำนวณเงินเดือน"
  2. ตารางแสดงพนักงานที่ยังปฏิบัติงานทุกคน ได้แก่ เงินเดือนรอบนี้ ชั่วโมง OT ค่า OT วันที่ขาด ยอดหัก และยอดสุทธิ
  • เงินเดือนรอบนี้ = เงินเดือนต่อเดือน ÷ 2 (เงินเดือนมาจากตำแหน่งของพนักงาน)
  • ค่า OT = ชั่วโมง × (เงินเดือน ÷ 240) × 1.5
  • หักขาดงาน = จำนวนวันที่ขาด × (เงินเดือน ÷ 30)
  • สุทธิ = เงินเดือนรอบนี้ + ค่า OT - หักขาดงาน

การลาและมาสายไม่มีผลต่อยอดเงินเดือน

แผนกและตำแหน่ง

  • เพิ่ม กรอกชื่อและรายละเอียด (แผนก) หรือเงินเดือนต่อเดือน (ตำแหน่ง) แล้วกด "+ เพิ่ม"
  • แก้ไข กด "แก้ไข" แล้วกรอกค่าใหม่ในหน้าต่างที่ขึ้นมา
  • ลบ กด "ลบ" แล้วยืนยัน ลบไม่ได้ถ้ายังมีพนักงานใช้แผนกหรือตำแหน่งนั้นอยู่

แจ้งขอเปลี่ยนแผนก/ตำแหน่ง/สิทธิ์

  1. เลือกเมนู "ข้อมูลแผนกและตำแหน่ง" แล้วเลือก "เปลี่ยนแผนก/ตำแหน่ง/สิทธิ์" เลือกพนักงาน แผนกใหม่ ตำแหน่งใหม่ (รายการตำแหน่งจะกรองตามแผนก) สิทธิ์ใหม่ ใส่เหตุผล แล้วกด "ส่งคำขอ"
  2. คำขอมีสถานะ "รออนุมัติ" ข้อมูลของพนักงานจะยังไม่เปลี่ยนจนกว่าผู้บริหารจะอนุมัติ
  3. กรองดูตามสถานะได้ที่แท็บด้านล่าง (ทั้งหมด รออนุมัติ อนุมัติแล้ว ไม่อนุมัติ)

ลาออก/พ้นสภาพ

  1. เมนู "ข้อมูลพนักงาน" กด "ลาออก" ที่แถวของพนักงาน เลือกวันที่มีผลและใส่เหตุผลในหน้าต่างที่ขึ้นมา แล้วกด "ยืนยัน" อีกครั้งในหน้าต่างยืนยัน
  2. ระบบเปลี่ยนสถานะเป็น "ลาออก/พ้นสภาพ" ปิดบัญชีล็อกอินของคนนั้น และเอาชื่อเขาออกจากการเป็นหัวหน้าของคนอื่น (ข้อมูลเดิมยังอยู่ ไม่ถูกลบ)
  3. ถ้าพนักงานยังมีคำขอเปลี่ยนตำแหน่ง/แผนกที่รออนุมัติ ต้องให้ผู้บริหารตัดสินคำขอก่อน
  4. ดูรายการทั้งหมดได้ที่เมนู "สถานะลาออก/พ้นสภาพ"

ปฏิทิน

แสดงเป็นรายเดือน เลื่อนเดือนด้วยปุ่ม ◀ ▶ ปีแสดงเป็น พ.ศ. วันหยุดนักขัตฤกษ์และวันหยุดสุดสัปดาห์ใช้สีต่างกัน วันที่ปัจจุบันมีกรอบสีน้ำเงิน แต่ละวันแสดงรายการขาด ลา มาสาย OT ของทุกคน (สูงสุด 3 รายการ ที่เหลือแสดงเป็น "+N รายการ")

สำรองข้อมูล

กด "สำรองข้อมูลและดาวน์โหลด" จะได้ไฟล์ JSON ที่มีข้อมูลแผนก ตำแหน่ง พนักงาน การลาออก รายงาน และรายชื่อบัญชี (ไม่รวมรหัสผ่านและรูปโปรไฟล์) ควรเก็บไฟล์ไว้ในที่ปลอดภัยและสำรองเป็นประจำ

คู่มือสำหรับผู้บริหาร

  • หน้าหลัก ดูภาพรวมพนักงาน การขาด ลา มาสาย และ OT ของวันนี้และของเดือนนี้ (ดูหัวข้อ "Dashboard และรายงาน")
  • รออนุมัติ เปิดมาที่แท็บ "รออนุมัติ" ตารางแสดงแผนก/ตำแหน่งเดิมและใหม่พร้อมเหตุผลที่ HR ระบุ กด "อนุมัติ" เพื่อเปลี่ยนแผนกและตำแหน่งของพนักงานทันที หรือกด "ไม่อนุมัติ" ซึ่งต้องระบุเหตุผลทุกครั้ง
  • ปฏิทิน ดูการขาด ลา มาสาย OT ของพนักงานทุกคน (แสดงเฉพาะชื่อต้น)
  • รายงานและ Dashboard ดูกราฟและตารางสรุปประจำเดือน ดาวน์โหลด CSV หรือพิมพ์ได้ (ดูหัวข้อ "Dashboard และรายงาน")

คู่มือสำหรับพนักงานทั่วไป

  • ข้อมูลส่วนตัว ดูรหัสพนักงาน ตำแหน่ง แผนก และข้อมูลติดต่อ เปลี่ยนรูปโปรไฟล์ได้ที่ปุ่ม "เปลี่ยนรูป" หรือคลิกรูปมุมบนซ้ายของแถบด้านบน
  • ขาด ลา มาสายของฉัน เลือกเดือน จะเห็นจำนวนวันลา ขาด มาสาย พร้อมวันลาคงเหลือ และรายการแยกตามวันที่
  • OT ของฉัน เลือกเดือน จะเห็นชั่วโมง OT รวมและจำนวนวันที่ทำ OT
  • เงินเดือนของฉัน เลือกเดือนและรอบ (1-15 หรือ 16-สิ้นเดือน) จะเห็นเงินเดือนรอบนั้น OT ยอดหัก และยอดสุทธิ พร้อมสูตรคำนวณ
  • ปฏิทิน เห็นเฉพาะรายการของตนเอง

ถ้าข้อมูลไม่ถูกต้อง ให้แจ้งฝ่าย HR เพื่อแก้ไข พนักงานแก้ข้อมูลเองไม่ได้ ยกเว้นรูปโปรไฟล์และรหัสผ่าน

Dashboard และรายงาน

หน้าหลัก (Dashboard)

แสดงข้อมูลล่าสุดจากฐานข้อมูลทุกครั้งที่เปิดหน้า ประกอบด้วย

  • การ์ดสรุปวันนี้ ลา ขาด มาสาย และทำ OT วันนี้ (ใช้สีเดียวกันทุกหน้า: ลา=เขียว ขาด=แดง มาสาย=ส้ม OT=ฟ้าเขียว) ส่วนจำนวนพนักงานทั้งหมดอยู่ที่หัวกราฟแผนก
  • การ์ดสรุปประจำเดือน ลา (วัน) ขาด (วัน) มาสาย (ครั้ง) และชั่วโมง OT ของเดือนปัจจุบัน
  • กราฟแท่งจำนวนพนักงานแยกตามแผนก และกล่อง คำขอรออนุมัติ (กด "ดูทั้งหมด" เพื่อไปหน้าคำขอ)

รายงานและแดชบอร์ด (เมนู "รายงานและแดชบอร์ด" มี 2 หน้า คือ "รายงาน" และ "แดชบอร์ด")

หน้า "รายงาน" มีการ์ดสรุป ตารางจำนวนพนักงาน ตารางรายคน และปุ่มดาวน์โหลด CSV/พิมพ์ ส่วนหน้า "แดชบอร์ด" มีการ์ดสรุปและกราฟต่าง ๆ เลือกเดือนที่ช่อง "เดือน" แล้วทุกส่วนที่เกี่ยวกับเดือนจะอัปเดตทันที (ค่าเริ่มต้นคือเดือนปัจจุบัน)

  • การ์ดสรุปประจำเดือน ขาด ลา มาสาย และชั่วโมง OT ของเดือนที่เลือก
  • จำนวนพนักงานตามแผนกและตามตำแหน่ง กราฟแท่งแนวนอนพร้อมจำนวนและเปอร์เซ็นต์ (นับเฉพาะพนักงานที่ยังปฏิบัติงาน ณ ปัจจุบัน)
  • ขาด ลา มาสาย รายวัน กราฟแท่งซ้อนตามวันที่ในเดือน แต่ละสีคือประเภท (ตามคำอธิบายสีเหนือกราฟ) วางเมาส์บนแท่งเพื่อดูตัวเลข
  • ชั่วโมง OT รายวัน กราฟแท่งของชั่วโมง OT รวมในแต่ละวัน
  • ขาด ลา มาสาย OT วันนี้ จำนวนรายการของแต่ละประเภทในวันนี้
  • 5 อันดับ พนักงานที่ขาด/ลา/สายมากที่สุด และพนักงานที่ OT มากที่สุดในเดือนที่เลือก
  • รายงานการทำงานรายคน ตารางขาด ลา สาย OT ของพนักงานแต่ละคน พร้อมแถวรวมและจำนวนผู้ลาออกในเดือนนั้น

ปุ่ม "ดาวน์โหลด CSV" ได้ไฟล์ตารางรายคนที่เปิดใน Excel ได้ (ภาษาไทยไม่เพี้ยน) ปุ่ม "พิมพ์รายงาน" พิมพ์หรือบันทึกเป็น PDF จากหน้าต่างพิมพ์ของเบราว์เซอร์ (เมนูและปุ่มจะถูกซ่อนในหน้าที่พิมพ์)

ตัวเลขทั้งหมดมาจากรายการที่ HR บันทึกในเมนู "การเข้างาน" และ "การทำงานล่วงเวลา (OT)" ถ้าตัวเลขไม่ตรงกับความเป็นจริง ให้ตรวจว่ามีการบันทึกครบหรือยัง

สำหรับผู้ดูแลระบบ: การติดตั้ง

สิ่งที่ต้องมี Node.js 18 ขึ้นไป และ PostgreSQL 14 ขึ้นไป

  1. สร้างผู้ใช้และฐานข้อมูลใน PostgreSQL: CREATE USER ems WITH PASSWORD 'รหัสผ่าน'; และ CREATE DATABASE ems OWNER ems; (รันทีละคำสั่ง)
  2. ในโฟลเดอร์โปรเจกต์ รัน npm install
  3. คัดลอก .env.example เป็น .env แล้วแก้ DATABASE_URL=postgresql://ems:รหัสผ่าน@localhost:5432/ems และตั้ง JWT_SECRET เป็นค่าสุ่มที่เดายาก
  4. รัน npm run setup เพื่อสร้างตารางและข้อมูลตัวอย่าง (รันซ้ำได้อย่างปลอดภัย)
  5. รัน npm start แล้วเปิด http://localhost:3000

บน Render สร้าง PostgreSQL แล้วตั้ง Environment ของ web service ให้มี DATABASE_URL (ใช้ Internal Database URL) และ JWT_SECRET จากนั้นตั้ง Start Command เป็น npm run setup && npm start

รีเซ็ตรหัสผ่านหรือปลดล็อกบัญชี รัน node reset-password.js ชื่อผู้ใช้ รหัสผ่านใหม่ คำสั่งนี้ตั้งสถานะบัญชีกลับเป็นใช้งานได้ด้วย

ข้อควรระวัง ห้ามนำไฟล์ .env ขึ้น GitHub เพราะมีรหัสผ่านฐานข้อมูล
